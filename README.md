## 原则 / Principles

- 不接收或保存 API Key
- 不替用户测试模型，不把“可访问”包装成性能结论
- 不卖排名，不因返佣改变排序
- 免费政策和中转站状态可能变化，使用前请回到来源页核对

数据与页面每日更新。失效链接、规则变化或新条目可在 [公开 Issue](https://github.com/xuhaitao/free-ai-directory-cn/issues/1) 提交证据。
